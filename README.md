# NLP & Machine Learning Projects

This repository contains a collection of my earlier Python projects exploring Natural Language Processing (NLP), text classification, and machine learning techniques. The notebooks were originally developed and published on Kaggle.

## 1. Language Identification using Machine Learning

This project explores automatic language identification using supervised machine learning and different text feature representations.

**Key components:**
- Preparation of a multilingual dataset covering 22 languages, extracted from an existing collection of CSV files with modified language labels.
- Text feature extraction using word-level and character-level n-grams.
- Implementation and comparison of Random Forest, Linear Support Vector Classifier (Linear SVC), and Logistic Regression.
- Evaluation of classification accuracy across different feature configurations.

The experiments use 22,000 text samples and compare multiple combinations of classifiers and feature representations.

**Original resources:**
- [Kaggle Notebook](https://www.kaggle.com/code/zarajamshaid/language-identification-machine-learning)
- [Language Identification Dataset](https://www.kaggle.com/datasets/zarajamshaid/language-identification-datasst)

## 2. Basic NLP on Disaster Tweets

An exploratory NLP notebook examining text preprocessing, feature extraction, and classification techniques using social media posts related to disasters.

**Techniques covered:**
- Text cleaning and preprocessing
- Tokenization and stopword removal
- Word frequency and bigram analysis
- CountVectorizer and TF-IDF
- Logistic Regression
- Model evaluation and feature selection

This notebook was adapted from the original work by [Holf Yuen](https://www.kaggle.com/code/holfyuen/basic-nlp-on-disaster-tweets) and is included as part of my earlier NLP learning and experimentation.

**Original notebook:** [Kaggle](https://www.kaggle.com/code/zarajamshaid/basic-nlp-on-disaster-tweets)
